# Call Timer

A minimal, hacker-style call timer that automatically ends calls after a set duration.

## Features
- Set a custom timer for calls
- Automatically ends phone calls
- Supports WhatsApp calls (experimental)
- Live countdown via notification
- Clean, distraction-free interface

## How it works
The app uses Android Accessibility Service to detect the call screen and perform the “End Call” action when the timer finishes.

No personal data is collected, stored, or shared.

## Notes
- Accessibility permission is required for automatic call ending
- WhatsApp support may vary across devices and versions

## Use case
Useful for limiting call duration, avoiding long calls, and managing time more efficiently.
